# Vaani Birthday Website

A small interactive birthday surprise.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait a minute or two for the public website link to appear.

The memory tiles are placeholders; replace them with personal photos only if you are comfortable sharing those photos publicly.
